# Shawon Haque Portfolio

Awwwards-winning portfolio website built with Next.js, TypeScript, Tailwind CSS, GSAP, and Framer Motion.

![Portfolio Preview](https://i.postimg.cc/m2Ghq87r/Screenshot-2026-07-31-161703.png)

## ✨ Features

- **Cinematic Loading Screen** - Animated stars, split text reveal with blur, scale, and opacity stagger
- **Custom Cursor** - Inner dot + outer ring with glow and magnetic hover effects
- **Smooth Scrolling** - Lenis integration for momentum scrolling
- **Dark Futuristic Design** - Deep backgrounds (#050505, #09090B, #0D1117)
- **Accent Colors** - Electric Purple, Neon Blue, Pink
- **Glassmorphism UI** - Blur effects, glass cards throughout
- **Advanced Animations** - GSAP ScrollTrigger, Framer Motion interactions

## 🛠 Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** GSAP, Framer Motion
- **Smooth Scroll:** Lenis
- **3D:** React Three Fiber (ready)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/simon141404-gif/shaown-haque.git

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 📁 Project Structure

```
src/
├── app/
│   ├── globals.css      # Global styles, animations, effects
│   ├── layout.tsx       # Root layout with fonts
│   └── page.tsx         # Main page component
└── components/
    ├── About.tsx        # About section
    ├── Contact.tsx       # Contact form
    ├── Cursor.tsx       # Custom cursor
    ├── Experience.tsx    # Work experience timeline
    ├── Footer.tsx       # Footer with social links
    ├── Hero.tsx         # Hero section with profile
    ├── LoadingScreen.tsx # Cinematic intro
    ├── Navbar.tsx       # Floating navigation
    ├── Projects.tsx      # Project showcase
    └── Skills.tsx       # Skills & expertise
```
